## A real-world alternative

Instead of one cloud environment holding live Canvas write credentials, make two: a read-only one for audits and briefings (a Canvas token on a read-only Canvas role, if your district offers one) and a write one you open only for publishing and grading. Cloud sessions run unattended, so a read-only default limits what a bad prompt can do.
